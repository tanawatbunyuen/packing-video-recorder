PACKINGDASHBOARDวิธีใช้งาน

Packing Video Recorder ใช้อย่างไร?

โปรแกรมนี้ใช้บันทึกวิดีโอระหว่างแพ็กสินค้า โดยใช้ Barcode / Order เป็นตัวเริ่มและหยุดการบันทึก เพื่อให้ค้นหาวิดีโอย้อนหลังได้ง่าย

1

ระบุชื่อพนักงาน

หน้า PACKING พิมพ์ชื่อผู้แพ็ก แล้วกด ใช้ชื่อนี้ โปรแกรมจะจำชื่อไว้ในเครื่องนี้

2

เลือกโฟลเดอร์วิดีโอ

กด เลือกโฟลเดอร์ แล้วเลือกพื้นที่ในเครื่องที่ต้องการเก็บไฟล์วิดีโอ อนุญาตสิทธิ์เมื่อ Browser ถาม

3

เลือกคุณภาพ

ค่าเริ่มต้นคือ 720p เหมาะกับงานทั่วไป หากต้องการประหยัดพื้นที่เลือก 480p หรือเลือก 1080p เมื่อต้องการรายละเอียดสูง

4

เปิดกล้อง

กด เปิดกล้อง และตรวจสอบภาพ Preview ให้เห็นพื้นที่แพ็กสินค้าชัดเจน สามารถกดปิดกล้องเมื่อไม่ได้ใช้งาน

5

ยิง Barcode เพื่อเริ่ม

ยิง Barcode ของ Order เช่น Order A ครั้งแรก โปรแกรมจะเริ่ม REC อัตโนมัติ จากนั้นแพ็กสินค้าตามปกติ

6

ยิง Barcode เดิมเพื่อจบ

เมื่อแพ็กเสร็จ ยิง Order A ซ้ำอีกครั้ง โปรแกรมจะหยุดและบันทึกวิดีโออัตโนมัติ

Workflow ที่พนักงานต้องจำ

ยิง Order A → เริ่ม REC → แพ็กสินค้า → ยิง Order A ซ้ำ → บันทึกวิดีโอ

ค้นหาวิดีโอย้อนหลัง

เข้าเมนู DASHBOARD → เลือกวันที่ → ดูรายการ Barcode → คลิกเลข Barcode ที่ต้องการ ระบบจะเปิดวิดีโอของ Order นั้นจากโฟลเดอร์ที่เลือกไว้

กรณี Barcode ซ้ำ

ถ้า Order เคยบันทึกสำเร็จแล้ว โปรแกรมจะไม่ให้อัดซ้ำ หากต้องการอัดใหม่ ให้ลบวิดีโอเดิมจาก Packing Log ก่อน แล้วจึงสแกน Barcode เดิมอีกครั้ง

วิดีโอเก่าเกิน 10 วัน

เมื่อพบวิดีโออายุเกิน 10 วัน โปรแกรมจะแจ้งเตือนและถามก่อนลบทุกครั้ง กด ยังไม่ลบ หากต้องการเก็บไว้ หรือ ลบวิดีโอเก่า เพื่อลบไฟล์และ Log

ข้อแนะนำ

ใช้ Google Chrome หรือ Microsoft Edge และเปิดโปรแกรมผ่าน GitHub Pages ไม่ควรเปิดไฟล์ index.html จาก ZIP โดยตรง แต่ละเครื่องต้องเลือกโฟลเดอร์และอนุญาตกล้องของเครื่องนั้นเอง
